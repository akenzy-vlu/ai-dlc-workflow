# T-01-06 — SkillFileDrawer: tree, raw content panel, and the row click

## Context

This is the UI increment that makes UOW-01 demoable end to end. `agent-run-drawer` is
the pattern to copy exactly (ADR-01): a container/view/props triad, opened from local
state on the parent page (`openRunId` → here, `openSkillId`), not a route. The Skills page
row has no click handler today (`skills-page.view.tsx` columns) — that inertness is what
this ticket removes.

Markdown rendering and syntax highlighting are explicitly **not** in this ticket (UOW-02)
— `skill-file-content.tsx` renders raw text for every file here, on purpose, so that
component is the one and only place UOW-02 changes.

## Implementation notes

- `skills-page.tsx`: add `const [openSkillId, setOpenSkillId] = useState<string | null>(null)`,
  render `<SkillFileDrawer skillId={openSkillId} onClose={() => setOpenSkillId(null)} />`
  — identical shape to how `agent-runs-page` / `board-page` already open `AgentRunDrawer`.
- `skills-page.view.tsx`: the skill name cell gets an `onClick={() => onOpenFiles(skill.id)}`
  (or an `onRow` handler scoped to that cell); the existing Install/Sync `<Button>`'s
  `onClick` calls `e.stopPropagation()` before its own handler so both stay independently
  clickable in the same row (AC-09). Route the click to the skill's catalog `id`, not to
  any one installation row — every installation-target row for the same skill shares one
  `id`, so this alone gives AC-11 for free.
- `skill-file-drawer.tsx`: fetches `useSkillFiles(skillId)` (T-01-04/05), holds
  `selectedPath` state defaulting to `SKILL.md` once the tree loads, fetches
  `useSkillFileContent(skillId, selectedPath)` for the selected file. Fetch failure on
  either query renders an error state with a retry action (AC-02).
- `skill-file-tree.tsx`: nests the flat `SkillFileNode[]` into Ant Design `Tree`'s
  `treeData` shape (group by directory segments), `onSelect` updates `selectedPath`.
- `skill-file-content.tsx`: given a `SkillFileContent`, renders `<pre>{content}</pre>` when
  `encoding === 'utf8'`; a "preview not available for this file type" placeholder when
  `encoding === 'binary'` (AC-07); a "truncated — too large to preview in full" notice
  above the content when `truncated` is true (AC-06). No Preview/Plain-text toggle here —
  UOW-02 adds it.
- `skill-file-drawer.view.tsx`: plain Ant Design `Drawer` composing the tree and content
  panels side by side, `onClose` wired straight through (AC-10).
