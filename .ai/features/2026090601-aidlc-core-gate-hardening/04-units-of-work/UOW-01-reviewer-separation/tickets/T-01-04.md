# T-01-04 — Replace the prose claim with the enforced rule in SKILL.md and methodology.md

## Context

`SKILL.md` states "an implementer cannot accept its own work: `submit` and `accept` are
separate commands requiring separate names", and `methodology.md` repeats it under Phase 4.
Both described behaviour the controller did not have. Now that it does, the wording should
say what is enforced and what is not — ADR-04 is explicit that a normalised string is not
an identity, and a reader who believes otherwise is worse off than one who knows the limit.

## Implementation notes

- State the rule as a refusal, and name its one escape hatch (`--no-review`, recorded).
- Add one line saying comparison is on a normalised name, so impersonation by typing
  someone else's name is possible and visible in the trail rather than prevented.
- Do not restate the ADR; link the behaviour to it.
- Leave the gate table's G4 row alone — evidence lands in UOW-03, and this file should not
  describe a rule that is not shipped yet.

## Done when

- [x] `SKILL.md` describes the refusal, not an expectation
- [x] The normalised-name limit is stated plainly in one sentence
- [x] `methodology.md` Phase 4 matches
- [x] No claim in either file describes behaviour that does not exist yet
