# T-02-02 — evidence.py — run a command under timeout, digest output, keep a bounded tail

## Context

A new sibling module rather than more of `aidlc.py`: the controller is already 1,300 lines,
and keeping execution in its own file means the risky part of this feature has one place to
review. It follows the existing sibling convention — `aidlc.py` imports `uow_graph` by
inserting its own directory on `sys.path`.

This module decides nothing about gates. It runs a command and reports what happened, the
same separation `ai-dlc-verify` keeps between `verify.py` and `runner/run.py`.

## Implementation notes

- `run(command, timeout, output_ceiling)` returns a plain dict: `exit`, `digest`, `tail`,
  `duration_ms`, `error`. Never raises.
- Digest is `sha256` over the **full** combined output; the tail is the last
  `output_ceiling` bytes. That pair is what makes a bounded record still verifiable.
- Merge stdout and stderr into one stream — a failing test's message is as often on one as
  the other, and interleaving preserves the reading order a human needs.
- Three distinct failure shapes, none of which may look like a pass: non-zero exit
  (`exit: n`), failure to start (`exit: None`, `error` names it), timeout (`exit: None`,
  `error` says timeout). Kill the whole process group on timeout, not just the child.
- Stdlib only: `subprocess`, `hashlib`, `time`. No shell interpolation of ticket data into
  the command beyond the documented `{tests}` substitution, which the caller does.
