# T-01-02 — Pin transcript rendering with a recorded transcript

## Context
T-01-01 turns stream-json on for everyone who never overrode `agents.json`. The risk that
justifies A-06 being an assumption at all is cosmetic — a transcript that renders as a wall
of JSON instead of prose. The existing spec covers individual event shapes; what is missing
is a whole run.

Record one real run's stdout (`claude -p --output-format stream-json --verbose` on a
throwaway prompt), trim the payload bulk the way the existing fixtures do, and assert on
the transcript it produces end to end.

## Implementation notes
- Add the recording as a fixture array in the spec file, alongside the existing cases
- Assert: the joined transcript contains no `{"type":` fragment
- Assert: `sessionId` is captured from the first event that carries one and survives every
  later event that does not — the `mergeTelemetry` behaviour, exercised through a real
  sequence rather than a synthetic patch
- Do not assert on cost or turn counts here; those belong to UOW-03

## Done when
- [x] A full recorded run translates to prose and tool lines with no raw JSON
- [x] `sessionId` is non-null after the sequence and unchanged by later eventless frames
- [x] The existing cases in the spec still pass untouched
- [x] `pnpm test` is green
