# T-01-01 — Built-in claude entry emits stream-json

## Context
`BUILT_IN` ships `claude` as `args: ['-p']`. Print mode is right; the missing half is the
output format. Without `--output-format stream-json --verbose` the CLI prints prose, the
translator returns `null` for every line, and `AgentTelemetry.sessionId` stays null — so
`isResumable` is false for every run anyone has ever made on a default install.

`--verbose` is required by the CLI when `--output-format stream-json` is used with
`--print`; without it the invocation is rejected, which would look like an agent that
cannot start.

Only the `claude` entry changes. `codex`, `cursor-agent` and `copilot` keep the args they
have — each has a different answer and none of them is verified here.

## Implementation notes
- `{ id: 'claude', ..., args: ['-p', '--output-format', 'stream-json', '--verbose'] }`
- Leave `promptVia: 'stdin'` alone; the prompt path is unchanged
- The merge in `list()` already lets an `agents.json` entry with `id: 'claude'` replace
  the built-in wholesale — do not special-case the new flags into an override

## Verification
Run live on this machine, 2026-08-28, from an empty directory:
`echo "..." | claude -p --output-format stream-json --verbose` — exit 0, four frames
(`system`, `rate_limit_event`, `assistant`, `result`), and **every one of them carries
`session_id`**. So a default-install run reports a session and `isResumable` is true once
it terminates. The `rate_limit_event` frame is already dropped by the translator, which is
why the transcript stays prose.

## Done when
- [x] A default-install run reports a non-null `sessionId` in its telemetry
- [x] `isResumable` is true for that run once it reaches a terminal status
- [x] An `agents.json` entry with `id: claude` still replaces the built-in entirely
- [x] The three other built-in entries are unchanged
