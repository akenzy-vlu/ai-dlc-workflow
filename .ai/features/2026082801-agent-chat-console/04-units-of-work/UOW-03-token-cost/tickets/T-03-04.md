# T-03-04 — Token panel in the run view

## Context
T-01-03 brought the telemetry object across to the web model; this extends it with the four
counts and renders them. Ordered after T-01-03 because both edit the same four files.

## Implementation notes
- Extend the web telemetry type with the same four nullable fields
- Render as a small labelled block in the drawer's existing `Descriptions` rail: Input,
  Output, Cache read, Cache write — and the dollar figure beside them
- Format with `Intl.NumberFormat` so 47200 reads as 47.2k, matching how a person talks
  about it
- A null count renders "not reported" in the secondary text colour. Never `0`, never `—`
  where a real zero could also appear
- Show the block only when at least one count or the cost is present; a run from a CLI that
  reports nothing gets no empty panel

## Done when
- [x] A run with counts shows all four, formatted
- [x] A run with null counts shows "not reported" for each, not 0
- [x] A run that reported nothing at all shows no panel
- [x] `pnpm typecheck` is green
